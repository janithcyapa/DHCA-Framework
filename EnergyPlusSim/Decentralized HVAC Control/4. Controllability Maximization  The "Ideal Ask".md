

Because a single scalar input ($u \ge 0$) multiplies the supply-indoor differentials for Temperature, Humidity, and CO2, the AHU supply states dictate the _direction_ of actuation in the state space. To maximize the local zone's controllability, we must ask the AHU Coordinator for supply conditions that align this actuation direction with the zone's current error direction.

### 7.1 The Actuation Ray (Gap Vector)

The direction the zone state is pushed by the actuator is defined by the gap between the supply air and indoor air:

$$g = \begin{bmatrix} T_s - T_{in} \\ W_s - W_{in} \\ C_s - C_{in} \end{bmatrix}$$

### 7.2 The Correction Vector ($e$) and Asymmetric Targets

We define a desired correction vector $e$ pointing from the current state toward the target. In alignment with ASHRAE standards, these targets are handled asymmetrically:

1. **Temperature:** Target the exact band center.
    
    $$e_T = T_{ref} - T_{in}$$
2. **Humidity:** Target the health-optimal Sterling sub-window (e.g., $W_{ref}$ corresponding to $45\% \text{ RH}$ at $T_{ref}$).
    
    $$e_W = W_{ref} - W_{in}$$
3. **CO2:** Treat strictly as a one-sided ceiling. The error is zero unless the ceiling is breached (or nearing a margin).
    
    $$e_C = \min(0, C_{limit} - C_{in})$$
    
    _(Note: If_ $C_{in} = 1100$ _and_ $C_{limit} = 1000$_,_ $e_C = -100$_, driving a request for fresher air. If_ $C_{in} = 600$_,_ $e_C = 0$_, saving energy)._
    

### 7.3 Dimensional Scaling Matrix ($S$)

Because raw units vary wildly ($CO_2$ is in ppm ~1000s, $W$ is in kg/kg ~0.001s, $T$ is in °C ~10s), raw dot products would be overwhelmed by $CO_2$. We introduce a diagonal scaling matrix $S$ mapping states to a dimensionless space based on their expected operating ranges ($\Delta_{max}$):

$$S = \begin{bmatrix} \frac{1}{\Delta T} & 0 & 0 \\ 0 & \frac{1}{\Delta W} & 0 \\ 0 & 0 & \frac{1}{\Delta C} \end{bmatrix}$$

### 7.4 The Linear Program and Closed-Form Solution

The objective is to choose valid AHU supply states $v_s = [T_s, W_s, C_s]^T$ that maximize the scaled dot product between the correction vector $e$ and the actuation ray $g$:

$$\max_{v_s} \quad J_{ahu} = (S e)^T (S g) = (S_T e_T)(S_T g_T) + (S_W e_W)(S_W g_W) + (S_C e_C)(S_C g_C)$$

Subject to the physical limits of the AHU's coils and dampers:

$$T_{s,min} \le T_s \le T_{s,max}, \quad W_{s,min} \le W_s \le W_{s,max}, \quad C_{s,min} \le C_s \le C_{s,max}$$

Since $J_{ahu}$ is purely linear with respect to the decision variables $T_s, W_s, C_s$, the maximization decouples into three independent decisions, yielding a **closed-form bang-bang solution**:

$$T_{s}^* = \begin{cases} T_{s,max}, & \text{if } e_T > 0 \text{ (Zone needs heating)} \\ T_{s,min}, & \text{if } e_T < 0 \text{ (Zone needs cooling)} \\ T_{neutral}, & \text{if } e_T = 0 \end{cases}$$$$W_{s}^* = \begin{cases} W_{s,max}, & \text{if } e_W > 0 \text{ (Zone needs humidification)} \\ W_{s,min}, & \text{if } e_W < 0 \text{ (Zone needs dehumidification)} \\ W_{neutral}, & \text{if } e_W = 0 \end{cases}$$$$C_{s}^* = \begin{cases} C_{s,min}, & \text{if } e_C < 0 \text{ (Zone exceeds } CO_2 \text{ limit, use outside air)} \\ C_{recirc}, & \text{if } e_C = 0 \text{ (Zone is safe, maximize return air recirculation)} \end{cases}$$

This vector $[T_s^*, W_s^*, C_s^*]^T$ forms the **"Ideal Ask"** that the zone broadcasts to the centralized AHU Coordinator.
