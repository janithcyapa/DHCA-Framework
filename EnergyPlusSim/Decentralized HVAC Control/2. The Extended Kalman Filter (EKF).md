# 2. The Extended Kalman Filter (EKF) — Updated

## 1. Augmented State Vector (Unchanged)

$$x_a = \begin{bmatrix} T_{in} \\ T_m \\ W_{in} \\ C_{in} \\ d_T \\ d_W \\ N_{occ} \\ \alpha_{ext} \\ \alpha_{int} \\ \beta_{air} \\ \beta_{mass} \\ d_C \end{bmatrix}_{12 \times 1}$$

Physical constants: $\alpha_{ext} = 1/R_{ext}$, $\alpha_{int} = 1/R_{int}$, $\beta_{air} = 1/C_{air}$, $\beta_{mass} = 1/C_{mass}$.

---

## 2. Non-Linear Dynamics

**Physical states (unchanged):**

$$\dot{x}_1 = x_{10}\!\left[x_8(T_{out}-x_1) + x_9(x_2-x_1) + x_7 q_{person} + \rho_{air}c_p u(T_s-x_1) + x_5\right]$$
$$\dot{x}_2 = x_{11}\!\left[x_9(x_1-x_2)\right]$$
$$\dot{x}_3 = x_{10}c_p\!\left[x_7 g_{w,person} + \rho_{air}u(W_s-x_3) + x_6\right]$$
$$\dot{x}_4 = x_{10}\rho_{air}c_p\!\left[x_7 g_{co2,person} + u(C_s-x_4) + x_{12}\right]$$

**Disturbance / occupancy states — Ornstein–Uhlenbeck (mean-reverting) instead of pure random walk:**

$$\dot{x}_5 = -\frac{1}{\tau}x_5 \quad (d_T), \qquad \dot{x}_6 = -\frac{1}{\tau}x_6 \quad (d_W)$$
$$\dot{x}_7 = -\frac{1}{\tau}x_7 \quad (N_{occ}), \qquad \dot{x}_{12} = -\frac{1}{\tau}x_{12} \quad (d_C)$$

with $\tau = 7200\ \text{s}$ (2 hours). Without this leakage, disturbance states drifted indefinitely when no strong sensor signal corrected them, causing long-term accumulation errors. The 2-hour time constant is slow enough to track sustained disturbances (occupied periods, persistent solar gains) but fast enough to bleed off stale estimates overnight.

**Structural parameters (static):**

$$\dot{x}_8 = \dot{x}_9 = \dot{x}_{10} = \dot{x}_{11} = 0$$

---

## 3. Jacobian Matrix $F$ (12 × 12)

The bottom eight rows remain zero. Updated rows 5–7 and 12 now include the OU decay:

**Rows 1–4 (physical states)** — identical to the original derivation.

**Rows 5–7 and 12 (disturbances) — updated:**

$$F_{5,5} = -\frac{1}{\tau}, \quad F_{6,6} = -\frac{1}{\tau}, \quad F_{7,7} = -\frac{1}{\tau}, \quad F_{12,12} = -\frac{1}{\tau}$$

All other elements in rows 5–7 and 12 are zero (same as before, structurally).

**Rows 8–11 (parameters):** all zero.

---

## 4. Discretisation

Sub-stepped Forward Euler with $n_{steps} = \max(1,\;\lfloor \Delta t / 1.0\rfloor)$ sub-steps per EnergyPlus timestep:

$$\Phi_k = I_{12} + F\,\Delta t_{sub}, \qquad \hat{x}_{k|k-1} \leftarrow \hat{x}_{k|k-1} + f(\hat{x})\,\Delta t_{sub}$$
$$P_{k|k-1} \leftarrow \Phi_k P_{k|k-1} \Phi_k^T + Q\,\Delta t_{sub}$$

Sub-stepping is applied in the predict phase; a single measurement update follows.

## 6. EKF Algorithm

**Predict (per sub-step):**
$$\hat{x}_{k|k-1} = \hat{x}_{k-1|k-1} + f(\hat{x}_{k-1|k-1})\,\Delta t_{sub}$$
$$P_{k|k-1} = \Phi P_{k-1|k-1}\Phi^T + Q\,\Delta t_{sub}$$

**Update (once after all sub-steps):**
$$y_k = z_k - H\hat{x}_{k|k-1}$$
$$S_k = HP_{k|k-1}H^T + R$$
$$K_k = P_{k|k-1}H^T S_k^{-1}$$
$$\hat{x}_{k|k} = \hat{x}_{k|k-1} + K_k y_k$$
$$P_{k|k} = (I - K_k H)P_{k|k-1}(I - K_k H)^T + K_k R K_k^T \quad \text{(Joseph form)}$$

Both $P_{k|k-1}$ and $P_{k|k}$ are symmetrised after each update: $P \leftarrow (P+P^T)/2$.

The Normalised Innovation Squared (NIS) is logged for filter health monitoring:

$$\text{NIS}_k = y_k^T S_k^{-1} y_k$$

For 3 measurements the 95% acceptance band is $[0.216,\;7.815]$.

---

## 7. State Clipping (Post-Update)

To prevent divergence on unmeasured states, hard physical bounds are applied after each update step:

| State | Clip range | Rationale |
|-------|-----------|-----------|
| $T_m$ (wall temp) | $[10,\;40]^\circ\text{C}$ | Cannot be lava; divergence was uncapped before this fix |
| $d_T$ | $[-5000,\;5000]\ \text{W}$ | Unmodelled sensible heat |
| $d_W$ | $[-0.01,\;0.01]\ \text{kg/s}$ | Unmodelled latent heat |
| $N_{occ}$ | $[0,\;\infty)$ | Non-negative headcount |
| $\alpha_{ext}$ | $[1,\;5000]$ | Conductance must be positive |
| $\alpha_{int}$ | $[1,\;5000]$ | Conductance must be positive |
| $\beta_{air}$ | $[10^{-7},\;10^{-4}]$ | Inverse thermal mass |
| $\beta_{mass}$ | $[10^{-9},\;10^{-5}]$ | Inverse thermal mass |
| $d_C$ | $[-500,\;500]\ \text{ppm/s}$ | Unmodelled CO₂ source |

The $T_m$ clipping was the primary fix for the divergence-to-thousands-of-degrees bug observed post-commissioning. Without it, $T_m$ was observable only via the air-node temperature residual and, in the presence of parameter uncertainty ($\beta_{air}$ near zero in early timesteps), could drift into physically impossible regimes.
