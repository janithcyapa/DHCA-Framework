# HVAC Multi-Zone Control Strategy — Updated Summary

**Layer 1** (per zone): EKF + two-stage QP flow command, then Ideal Ask with flow-authority taper.  
**Layer 2** (central): AHU Coordinator QP arbitrates all zone asks into physical setpoints.

---

## Architecture Overview

```
┌──────────────────────────────────────────────────────────┐
│ Zone Controller × N                                      │
│                                                          │
│  EKF (12-state)  ──►  Phase-1 MPC QP  ──►  u_cmd       │
│    (OU disturbances,     (deadband +         │           │
│     state clipping)       centering)         │           │
│                                              ▼           │
│                         Phase-2 Ideal-Ask QP ──► Z_ask  │
│                           (with flow-authority taper)    │
└────────────────────┬─────────────────────────────────────┘
                     │ {T_s*, W_s*, C_s*, u_cmd, S_i} × N
                     ▼
┌──────────────────────────────────────────────────────────┐
│ AHU Coordinator                                          │
│                                                          │
│  Arbitration QP  ──►  [T_cc, T_hc, γ]                  │
│  (hard constraints,    ──► rate-limited setpoints        │
│   CO₂ via γ)           ──► written to EnergyPlus        │
└──────────────────────────────────────────────────────────┘
```

## Layer 1: Zone Controller

### EKF (Updated)

12-state augmented vector: $[T_{in}, T_m, W_{in}, C_{in}, d_T, d_W, N_{occ}, \alpha_{ext}, \alpha_{int}, \beta_{air}, \beta_{mass}, d_C]$.

Key changes from original design:

| Change | Detail |
|--------|--------|
| **OU disturbance model** | $d_T, d_W, N_{occ}, d_C$ now follow $\dot{x} = -x/\tau$ ($\tau = 7200\text{s}$) rather than pure random walk; prevents indefinite drift of unobservable states |
| **State clipping** | Hard physical bounds applied after each update; $T_m$ clipped to $[10,40]^\circ\text{C}$ (fixes divergence-to-thousands bug), disturbances and parameters clipped to physically realistic ranges |
| **Sub-stepped predict** | Euler integration sub-steps at 1 s intervals within each EnergyPlus timestep |
| **Joseph-form update** | $(I-KH)P(I-KH)^T + KRK^T$ for improved numerical symmetry |
| **NIS logging** | $\text{NIS}_k = y_k^T S_k^{-1} y_k$ logged for 95% acceptance band diagnostics |

### Stage 1 MPC (Flow Rate) — Updated

| Feature | Original | Updated |
|---------|----------|---------|
| Objective | Flow min + slack | Flow min + quadratic centering + slack |
| Centering | None | $q_T\|F_T U + g_T - T_{ref}\|^2 + q_W\|F_W U + g_W - W_{ref}\|^2$ in objective |
| Slew rate | Penalty only ($r_\Delta$) | Penalty **and** hard constraint block 10: $|u_k - u_{prev}| \le \Delta u_{max}$ |
| Linear slack term | None | $\mu_T \epsilon_T$ asymmetric push on temperature slack |
| OSQP format | One-sided $A z \le b$ | Two-sided $l \le A z \le u$ (native OSQP format) |
| Horizon $N$ | 20 | 20 |
| Fallback | Hold $u_{prev}$ | Proportional controller with slew-rate cap |

**Constraints (10 blocks × N):**

| Block | Constraint |
|-------|-----------|
| 1–2 | Soft temperature band (two-sided) |
| 3–4 | Soft humidity band (two-sided) |
| 5 | Soft CO₂ ceiling |
| 6–8 | $\epsilon_{T,W,C} \ge 0$ |
| 9 | $u_{min} \le u \le u_{max}$ |
| 10 | **Hard slew rate**: $\|u - u_{prev}\|_\infty \le \Delta u_{max} = 0.05\ \text{m}^3\text{/s}$ |

### Stage 2 Reverse QP (Ideal Ask) — Updated

| Feature | Original | Updated |
|---------|----------|---------|
| Neutral targets | Fixed $T_{neutral}, W_{neutral}$ | **Dynamic**: estimated from mixed-air blend each timestep |
| $\gamma$ estimation | N/A | $\hat\gamma = \text{clip}((C_{in}-C_s)/(C_{in}-C_{out}), 0, 1)$ |
| Input horizon | Per-step trajectory | **Constant $Z$** held over $N$ steps (consistent with what AHU can actually deliver) |
| Low-flow behaviour | Asks snap to extreme | **Flow-authority taper**: ask blends toward neutral when $u_{cmd}$ is near $u_{min,vent}$ |
| $u_{min,vent}$ | ~1% of $u_{max}$ | Raised to $7.5\%$ of $u_{max}$ (~$0.15\ \text{m}^3\text{/s}$) |

**Flow-authority taper:**
$$\text{taper} = \text{clip}\!\left(\frac{u_{cmd} - u_{min,vent}}{u_{max} - u_{min,vent}},0,1\right), \qquad Z_{broadcast} = \text{taper}\cdot Z^* + (1-\text{taper})\cdot Z_{neutral}$$

This eliminates limit-cycle chatter that occurred when low-flow zones were injecting extreme asks into the coordinator, which then overcorrected, causing the zone MPC to open the damper further, which resumed the coil, which overcorrected again.

## Layer 2: AHU Coordinator (Updated)

### Inputs (per timestep)

| Name | Description | Source |
|------|-------------|--------|
| Zone bundles | $\{T_{s,i}^*, W_{s,i}^*, C_{s,i}^*, u_{cmd,i}, S_i\}$ | Layer 1 |
| $T_{out}, T_{ret}$ | Outdoor and return-air temperatures | EnergyPlus nodes |
| $C_{out}, C_{ret}$ | Outdoor and return-air CO₂ | EnergyPlus nodes |
| $T_{fan,out}, T_{hc,out}$ | Fan and heating-coil outlet temps | EnergyPlus nodes (fan $\Delta T$ estimator) |

### QP (Updated)

The coordinator solves one 3-variable QP ($[T_{cc}, T_{hc}, \gamma]$) with aggregated zone weights:

$$\omega_i = q_T u_i^2 S_i^3, \quad \psi_i = q_W u_i^2 S_i^3, \quad \chi_i = q_C u_i^2 S_i^3$$

Each actuator tracks a **different** physical channel:
- $T_{cc}$ → **humidity** (via linearised $w_{sat}$, psychrometric coupling)
- $T_{hc}$ → **temperature** (with online fan heat-rise correction)
- $\gamma$ → **CO₂** dilution (via CO₂ mass balance in constraint row 6)

**Key QP changes vs. original:**

| Feature | Original notes | Current code |
|---------|---------------|-------------|
| CO₂ tracking | Mentioned in CO₂ constraint | Explicit $\chi_i$ terms in $P_{33}$ and $q_3$ |
| $S_i$ exponent | Linear weight | **Cubic** ($S_i^3$) — sharper priority contrast |
| Fan $\Delta T$ | Fixed offset | **Online adaptive**: EMA of measured $T_{fan,out} - T_{hc,out}$ |
| Hessian cross-terms | $P_{12}$ only | $P_{12}$ (heating coupling) **and** $P_{13}$ (cooling–ventilation coupling) |

### Outputs

| Actuator | Value |
|----------|-------|
| `CC_Temp_SP` | $T_{cc}^*$ |
| `HC_Temp_SP` + `SAT_Sch_SP` | $T_{hc}^*$ |
| `OA_Flow_SP` | $\gamma^* \times 2.5\ \text{kg/s}$ |
| `Hum_Sch_SP` / `CC_Hum_SP` / `CC_Hum_Max_SP` | $w_{sat}(T_{cc}^*)$ |
| `{zone}_Reheat_SP` × N | Fixed at $10.0^\circ\text{C}$ (reheater suppression) |

### Rate Limiting

$\alpha = 0.4$, $\Delta T_{max} = 1.5^\circ\text{C}$ per timestep for coils; $\Delta\gamma_{max} = 0.1$ per timestep for damper.

## Implementation Notes

- All three QP layers fall back gracefully when OSQP fails: proportional control (zone flow), heuristic bang-bang (Ideal Ask), or previous setpoints held (coordinator).
- The dew-point actuation split (separating `CC_Temp_SP` from `SAT_Sch_SP` / `HC_Temp_SP`) was a critical bug fix — the original code pinned delivered supply air near the cooling coil dew point regardless of coordinator intent.
- Reheater suppression ($10^\circ\text{C}$ hardset on all `{zone}_Reheat_SP`) enforces the no-reheat design constraint and prevents EnergyPlus's default VAV logic from interfering.
- Zone $T_{s,min} = 10^\circ\text{C}$ is intentionally stricter than the coordinator's $T_{coil,min} = 5^\circ\text{C}$: the coordinator's feasible window is a superset of what any zone requests.
